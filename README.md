# hud-checklist-data

Airport frequencies for the HUD Checklist glasses app, built from the FAA NASR 28-day subscription.

- `docs/freq.json` is published at `https://jcfi92.github.io/hud-checklist-data/freq.json`
- A GitHub Action checks for a new NASR cycle every Thursday and updates the file.

Reference only. Verify frequencies against the current Chart Supplement before flight.
